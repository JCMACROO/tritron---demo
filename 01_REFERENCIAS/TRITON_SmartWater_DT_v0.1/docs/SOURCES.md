# Open-source / public model sources

- **WNTR (USEPA)**: https://github.com/USEPA/WNTR — Revised BSD license.
- **WNTR documentation**: https://usepa.github.io/WNTR/
- **EPANET Net3 model**: https://raw.githubusercontent.com/USEPA/WNTR/main/examples/networks/Net3.inp
- **EPANET**: https://www.epa.gov/water-research/epanet

The full WNTR backend loads the official Net3 model from the WNTR model library (or an explicit `.inp`).
The Lite backend contains only a small connected demonstrator derived from a subset of Net3 node/pipe parameters and is marked as a non-EPANET proxy.
